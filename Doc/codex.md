# 🐾 Monster Farm

## Vision
Cute and addictive multiplication game for kids (6–10).

Core loop:
care → play → reward → evolve

## Stack
- Next.js (App Router)
- React
- Tailwind CSS
- Framer Motion
- LocalStorage
- Vercel deployment

## Key Goals
- Fun first, learning hidden
- Short sessions (<5 min)
- Emotional attachment to creatures

## Game Modes
- Farm (main hub)
- Training (mini-game)
- Battle (challenge)

## Constraints
- No backend required
- Runs instantly
- Mobile-first UI
